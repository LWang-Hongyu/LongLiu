# 信息获取模块说明（时间戳和字节数）

## 概述

信息获取模块负责在NCCL通信过程中实时收集两个关键指标：
1. **时间戳**：记录通信操作的开始和结束时间
2. **字节数**：记录每次通信操作传输的数据量

这些信息用于后续的性能分析和DSCP动态调整。

---

## 1. 时间戳获取

### 1.1 核心函数

**位置**：`src/include/comm_stats.h` (第97-101行)

```97:101:src/include/comm_stats.h
static inline double ncclCommStatsGetTime() {
  struct timespec ts;
  clock_gettime(CLOCK_MONOTONIC, &ts);
  return (double)ts.tv_sec + (double)ts.tv_nsec / 1e9;
}
```

### 1.2 技术特点

- **时钟类型**：使用 `CLOCK_MONOTONIC`
  - 单调递增，不受系统时间调整影响
  - 适合测量时间间隔和性能
  - 从系统启动后的某个固定点开始计时

- **精度**：纳秒级精度
  - `tv_sec`：秒数
  - `tv_nsec`：纳秒数
  - 返回值：转换为双精度浮点数（秒）

- **性能**：`static inline` 函数，编译时内联，无函数调用开销

### 1.3 使用场景

时间戳在以下位置被获取：

1. **通信操作开始**：`ncclCommStatsStartOp()` (第147行)
   ```c
   op->startTime = ncclCommStatsGetTime();
   ```

2. **通信操作结束**：`ncclCommStatsEndOp()` (第171行)
   ```c
   double endTime = ncclCommStatsGetTime();
   ```

3. **Epoch开始**：`ncclDscpAdapterStartEpoch()` (第80行)
   ```c
   epochStats->startTime = ncclCommStatsGetTime();
   ```

4. **Epoch结束**：`ncclDscpAdapterEndEpoch()` (第113行)
   ```c
   epochStats->endTime = ncclCommStatsGetTime();
   ```

## 4. 调用流程

### 4.1 通信操作记录流程

```
用户调用 NCCL API (如 ncclAllReduce)
    ↓
ncclEnqueueCheck() (src/enqueue.cc)
    ↓
ncclCommStatsStartOp() (记录开始时间和字节数)
    ↓
执行通信操作
    ↓
ncclCommStatsEndOp() (记录结束时间)
```

### 5.2 性能指标计算

基于获取的时间戳和字节数，可以计算：

- **通信带宽**：`(totalBytes * 8) / commDuration` (Gbps)
- **计算时长**：`totalDuration - commDuration`
- **优先级 (ui)**：`ai / ei`（实际时间 / 期望时间）

## 6. 线程安全

所有统计数据的访问都通过互斥锁保护：

**位置**：`src/misc/comm_stats.cc`

- `pthread_mutex_lock(&stats->mutex)` - 获取锁
- `pthread_mutex_unlock(&stats->mutex)` - 释放锁

确保多线程环境下数据的一致性。

## 7. 总结

信息获取模块的核心功能：

1. ✅ **高精度时间戳**：使用 `CLOCK_MONOTONIC` 获取纳秒级时间戳
2. ✅ **实时字节数统计**：从通信操作参数中直接获取
3. ✅ **多级数据组织**：操作级 → 迭代级 → Epoch级
4. ✅ **线程安全**：通过互斥锁保护共享数据
5. ✅ **低开销**：内联函数，最小化性能影响

这些信息为DSCP动态调整提供了准确的数据基础。
